Stop what you're doing.

You've been working on this problem for a while and may be stuck in
a local optimum. Take a completely fresh perspective on the code or error
the user named (if they named nothing — the one you were just working on):

1. Forget all previous attempts and assumptions
2. Read only that code/error — nothing else
3. Describe in plain language what this code actually does
4. List what could cause the observed symptom — starting from
   the most obvious, not the most sophisticated
5. Pick the simplest explanation and verify it first

Do not continue previous line of reasoning.
